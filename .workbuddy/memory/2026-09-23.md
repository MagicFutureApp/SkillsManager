## 17:49 修 admin 页 `admin:191 Uncaught SyntaxError: Invalid or unexpected token`
- 根因:`renderAdminPage()` 返回的是**外层模板字符串**。`parseCsv` 里写的 `if (c === "\r")` / `"\n"` 被 TS 模板字符串当成转义序列,输出成真实回车/换行字符,浏览器端 JS 字符串被截断→语法错。
- 修法:`admin-page.ts` 第 200-201 行 `"\r"`→`"\\r"`、`"\n"`→`"\\n"`(转义反斜杠,让产物 HTML 里保留字面量 `\r`/`\n`)。
- 复用验证套路(node 经验证可用):`node --experimental-strip-types --input-type=module` 动态 `import('file:///.../admin-page.ts')`(Windows 绝对路径必须 file:// URL)→ 抽 `<script>` 内容 → `node --check` 校验浏览器端 JS 语法。本次抽出的脚本 5225 字节、`node --check` 通过 → 浏览器报错消除;cache-manager tsc 仍 exit 0。
- 教训:在 TS 模板字符串里内联 JS/正则/转义时,凡含 `\r \n \t \\` 等都必须双写反斜杠。
