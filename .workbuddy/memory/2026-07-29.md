## 本地联调：给 KV 写 latest manifest（让 /api/releases/latest 返回 200）
- 该路由读取 `env.SKILLS_MANAGER_RELEASE_MANIFEST.get("latest", "json")`，KV 为空时返回 404（本地 dev 默认就是空的，属正常）。
- 种子命令（仅本地、不碰生产）：`pnpm --filter @skills-manager/landing exec wrangler kv key put latest --path=<json文件> --binding=SKILLS_MANAGER_RELEASE_MANIFEST --local`。
- manifest 必须是合法 `ReleaseManifest`（`src/lib/release-manifest.ts` 的 `isReleaseManifest`）：`schemaVersion:1` + `version`/`tag`/`publishedAt`/`releaseUrl` + `downloads.{windows,macos,linux}.{name,url,sha256}`，否则校验不过仍 404。
- 写入后需**重启 `worker:dev`** 让 dev server 重新加载本地 KV；若仍 404，可能是 @cloudflare/vite-plugin 的本地 KV 持久化路径与 `wrangler --local` CLI 不同，可改用 `--remote`（需 `wrangler login`，影响线上）或加临时 seed 路由。
