## 代码签名方案咨询

用户询问如何为 Skills Manager Electron 应用签名（当前 Windows/macOS 均未签名）。

### 现状分析
- `electron-builder.yml`: `mac.identity: null` 禁用 macOS 签名
- CI workflow: `CSC_IDENTITY_AUTO_DISCOVERY: "false"` 关闭自动签名
- Windows: 无任何 win.sign 配置
- README 已注明 "The current packages are unsigned"

### 方案对比
| 平台 | 方案 | 成本 | 说明 |
|------|------|------|------|
| Windows | SignPath OSS 免费计划 | $0/年 | 开源项目免费，发布者显示 "SignPath Foundation"，需审批约1周 |
| Windows | Azure Trusted Signing | ~$10/月 | 仅 US/Canada 客户 |
| Windows | OV 证书 (.pfx) | $70-300/年 | 无即时 SmartScreen 声誉 |
| Windows | EV 证书 + 云签名 | $300-1500/年 | 立即通过 SmartScreen |
| macOS | Apple Developer ID + 公证 | $99/年 | 唯一规范路径 |

### 用户选择
- Windows: SignPath 免费 OSS
- macOS: 准备注册 Apple Developer Program
- 签名位置: CI (GitHub Actions)

### 已创建

## 免费签名方案补充 & Homebrew Cask 配置

用户询问更多免费方案。

### Windows 免费方案汇总
| 方案 | 费用 | 发布者 | 关键门槛 |
|------|------|--------|---------|
| SignPath | $0 | SignPath Foundation | 开源+已发布（已选） |
| OSSign | $0 | OSSign | 目前暂停受理，需6个月活跃 |
| Certum 开源 | $0 | 自己的名字 | GitHub 1k+ stars + 中国国籍 |
| 自签名 | $0 | 自己 | SmartScreen 照弹 |

### macOS 免费方案: Homebrew Cask
- 不需要 Apple Developer 账号、不需要签名公证
- 用户通过 `brew install --cask skills-manager` 安装
- Homebrew 放到 /Applications 绕过 Gatekeeper

### 实施内容
1. 创建 `Casks/skills-manager.rb` — Homebrew Cask 定义（版本 0.2.0，含实际 sha256）
2. 修改 `.github/workflows/build-desktop-installers.yml` — release job 新增 checkout main 分支 + 自动更新 cask 版本号和 sha256 + git commit & push
3. 修改 `README.md` — 新增 "Install" 章节，包含 Homebrew 安装和直接下载说明

### Cask 文件关键配置
- `depends_on macos: ">= :monterey"` — Electron 41 最低要求 macOS 12
- `depends_on arch: :arm64` — 当前仅构建 arm64
- zap trash: `~/Library/Application Support/skills-manager`

### 使用方式
```bash
brew tap MagicFutureApp/skills-manager https://github.com/MagicFutureApp/SkillsManager
brew install --cask skills-manager
```
