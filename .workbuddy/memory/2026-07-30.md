## pnpm 下 wrangler 命令在两个 app 解析不一致的根因
- 现象：`pnpm exec wrangler` 在 `apps/landing` 能用，在 `apps/cache-manager` 报 `Cannot find module .../cache-manager/node_modules/wrangler/bin/wrangler.js`。
- 根因：两个 package.json 都声明了 wrangler（devDependencies），与声明无关。wrangler 被 hoist 到工作区根 `node_modules/wrangler`（真实包，根 `.bin/wrangler` 有效）。
  - landing 本地无 `.bin/wrangler` → 回退到根目录有效 wrangler → 成功。
  - cache-manager 本地有 `.bin/wrangler` 软链，但本地 `node_modules/wrangler` 不存在（只 hoist 在根）→ 悬空软链 → 失败。属 pnpm `.bin`/包软链生成不同步。
- 补充：cache-manager 的 npm scripts 用显式路径 `node ../../node_modules/wrangler/bin/wrangler.js`，所以 `pnpm run dev/deploy` 本身能跑；只有直接敲 `wrangler` 才踩坑。
- 修复：删 `apps/cache-manager/node_modules/.bin/wrangler` 悬空软链，或根目录重跑 `pnpm install`/`pnpm install --force`。
